### 💻 О моем проекте: **NovaScript**
> **NovaScript** — это экосистема, в которой веб-структура, документация и шаблоны игр создаются и компилируются с помощью кастомного DSL. Никакого лишнего мусора — только чистая архитектура и высокая скорость работы.

* **🐍 Бэкенд и Компилятор:** Написаны на Python (`interpreter.py`, `to_html.py`).
* **🌐 Генерация сайтов:** Автоматическое превращение `.nova` скриптов в современные веб-страницы.
* **🎮 2D-Геймдев:** Встроенные шаблоны для создания аркад прямо в браузере.
